# CPS Site Fatec Itu — Widgets

Coleção de widgets independentes em **HTML, CSS e JavaScript**, originalmente desenvolvidos para complementar o site institucional da **Fatec Itu**.

O projeto nasceu de uma necessidade prática: criar componentes visuais e funcionais que pudessem ser incorporados ao site sem a necessidade de modificar diretamente sua estrutura principal.

Atualmente, o projeto **não está em desenvolvimento ativo**, mas permanece público no GitHub para que o código possa ser consultado, reutilizado, adaptado ou aprimorado por quem tiver interesse.

---

## 📋 Sobre o projeto

Os widgets foram desenvolvidos para serem utilizados em um ambiente baseado em WordPress, onde determinadas alterações no código principal do site não eram possíveis ou convenientes.

A solução foi criar pequenos componentes independentes utilizando tecnologias web simples:

* HTML
* CSS
* JavaScript

A proposta era manter os widgets:

* simples;
* fáceis de editar;
* fáceis de incorporar a páginas existentes;
* sem dependências desnecessárias;
* compatíveis com a estrutura do site para a qual foram originalmente desenvolvidos.

## 🧩 Widgets disponíveis

### 🎓 Cards de Cursos

**Arquivo:** `card-cursos.html`

Exibe os cursos da Fatec Itu em formato de cards clicáveis.

---

### 📸 Instagram

**Arquivo:** `divisao-instagram.html`

Componente visual criado para direcionar visitantes ao perfil da Fatec Itu no Instagram.

---

### 🤝 Empresas Parceiras

**Arquivo:** `empresas-parceiras.html`

Exibe empresas e instituições parceiras em formato de cards.

---

### 📢 Overlay / Destaque

**Arquivo:** `overlay.html`

Componente utilizado para apresentar informações, campanhas ou chamadas de destaque sobre o conteúdo principal da página.

---

### 🖼️ Slider

**Arquivo:** `slider.html`

Slider de imagens com navegação manual e automática.

---

### 🎬 Vídeo

**Arquivo:** `video.html`

Componente visual baseado em vídeo para apresentação de conteúdos institucionais.

---

### 🩹 Tapa-Buraco

**Arquivo:** `tapa-buraco.js`

Script utilizado para substituir imagens ausentes ou que não puderam ser carregadas por uma imagem padrão.

## 🚀 Utilização

Os arquivos podem ser utilizados como referência ou adaptados para outros projetos.

Para utilizar um widget:

1. Escolha o arquivo correspondente.
2. Analise as dependências e recursos utilizados.
3. Copie ou adapte o código para o seu projeto.
4. Ajuste URLs, imagens, textos e estilos conforme necessário.
5. Teste o componente no ambiente de destino.

> **Importante:** os widgets foram originalmente desenvolvidos para um ambiente específico. Alguns deles podem depender de classes CSS, bibliotecas, estrutura HTML ou recursos externos existentes no site da Fatec Itu.

Por isso, pode ser necessário realizar adaptações antes de utilizá-los em outro projeto.
